# 関数のたしかめ

中学1〜3年の関数を、学年別の選択式問題で確認するシンプルな学習アプリです。

## 使い方

`index.html` をブラウザーで開くと使えます。ビルドや追加パッケージは不要です。

学年、単元、難易度（やさしい・ふつう・チャレンジ）の順に選びます。選んだ単元と難易度に合わせて毎回異なる5問がランダムに出題されます。数値や条件を変えて問題を生成するため、同じ設定で何度でも練習できます。1回の挑戦内では同じ問題は重複しません。答えを選ぶと自動で採点され、解説ボタンから説明を確認できます。最後に結果が表示され、同じ難易度に再挑戦することもできます。

トップ画面の「学習の足あと」では、解いた問題数・正解率・連続学習日数、過去7日間の学習グラフ、単元ごとの記録を確認できます。回答ごとに記録し、ブラウザーのローカルストレージに保存するため、同じブラウザーで次回開いたときも記録が残ります。

## 問題の範囲

- 中学1年：比例、反比例
- 中学2年：一次関数の式、変化の割合とグラフ
- 中学3年：式・グラフ・変域、変化の割合

中学校数学で扱う基本事項をもとにした問題です。教科書や学校によって学習順序・表現が異なる場合があります。問題の出題パターンは `app.js` の `questionGenerators` を更新してください。

難易度は、やさしい問題では小さな正の数を中心にし、ふつうでは正負の数を含め、チャレンジでは数の範囲を広げて出題します。
